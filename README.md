# 中国最不无聊的网站 · 熊出没传送站

课程作业：HTML + CSS + JavaScript 做的恶搞网站（熊出没主题），纯属娱乐。

## 在线访问（GitHub Pages）

https://fengshucheng071221.github.io/bear-joke-site/

## 功能

- 固定导航 + 锚点高亮 + 移动端菜单
- Hero 区（圆形熊头像、漂浮动画、数据标签）
- 实时数据条：访客数 / 在线熊数 / 浪费秒数 / 笑声分贝
- 关于本站三卡片、院长致辞、表情包中心（点击弹出灯箱）
- 浪费时间计时器、快问快答（折叠）
- 真假网址链接卡、留言墙（localStorage 持久化）
- 回到顶部、滚动出现动画、彩蛋（连点熊大 5 次）

## 文件结构

```
index.html       主页面
熊大.html        同一页面副本（保留原名）
css/style.css    样式
js/site.js       交互
img/             表情包图片
```

## 本地打开

双击 `index.html` 即可（无外部依赖，离线可用）。
